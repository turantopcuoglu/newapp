# Uygulamanın tamamına yayılan mod temaları

8 Eylül 2026 · Yeni tasarım önerisi · Uygulama koduna uygulanmadı.

Önceki çalışmadaki vurgu rengi yaklaşımı yerine, zemin/kart/yazı/ikon/gezinme/form/grafik/pencere/dekoratif varlıkları birlikte değiştiren üç dünya önerilir.

1. **Yorgunum — Kadife akşam:** mürdüm, mat gül kurusu, şampanya.
2. **Sakinim — Durgun su:** petrol, yeşim, inci.
3. **Enerjik — Kayısı şafağı:** açık kayısı, kum, kakao, bakır.
